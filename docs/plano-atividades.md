## Por que está lá e não aqui

Este repositório guarda o **conceito** — visão, arquitetura, decisões. O plano é
uma lista de trabalho executável, com comandos que provam cada conclusão, e ele
aponta para commits de um repositório específico. Dois arquivos idênticos em
repositórios diferentes divergem na primeira edição; um ponteiro não.

- **Arquitetura e decisões:** este repositório (`08-arquitetura-v2.md`, `09-decisoes.md`)
- **Plano executável, charts, código, bundle:** repositório `datalake-doomsday-env`
